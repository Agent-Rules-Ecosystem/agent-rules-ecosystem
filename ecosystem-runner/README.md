# 🌌 Ecosystem Runner & Bootstrapper

Esta carpeta (`ecosystem-runner`) contiene el paquete autónomo y aislado para ejecutar auditorías del ecosistema y gestionar backlog global (`$workeco`) sin alterar las plantillas canónicas de `agent-rules-ecosystem`.

## Uso Rápido
1. Copia o arrastra `ECOSYSTEM.md` a cualquier proyecto o workspace.
2. Escribe `$ecosystem` o `ejecuta ECOSYSTEM.md` en el chat del agente.
3. Se activará el **Modo Cavernícola** (comunicación lacónica) y la auditoría de los 11 Cores & Skills.
4. Registra tareas ecosistémicas con `$workeco [descripción]`.
