# Catálogo Oficial de Skills del Ecosistema (`*-agent-skill`)

Este directorio contiene la referencia e índice de habilidades técnicas inyectables (`*-agent-skill`) compatibles con los Cores de gobernanza.

## Skills Disponibles

| Skill | Repositorio | Descripción / Dominio |
|---|---|---|
| `lore-agent-skill` | `xolotl-hub/lore-agent-skill` | Gestión de lore, cronología y entidades narrativas |
| `second-brain-agent-skill` | `xolotl-hub/second-brain-agent-skill` | Gestión del conocimiento, e-discovery y grafos |
| `grapho-agent-skill` | `xolotl-hub/grapho-agent-skill` | Análisis AST y radiografía de código |

## Instalación en Proyectos Cliente

```bash
git submodule add git@github.com:xolotl-hub/<skill-name>.md .skill/<skill-name>
```
